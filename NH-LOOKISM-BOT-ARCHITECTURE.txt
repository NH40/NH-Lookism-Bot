1. НАЗНАЧЕНИЕ
Telegram-бот — текстовая MMORPG по мотивам веб-сериала Lookism:

Фазы прогрессии: Gang → King → Fist (убрана) → Emperor

Кланы: создание, войны, казна, земля, магазин, ранги

Карточная система: гача, колода, слияние, дуэли, PvP

Рейды: клановые боссы, крафт фрагментов (УИ, МГ, Путь, Бизнес)

Банк/Казино: кредиты, вклады, хранилище, блэкджек, слоты, покер

Биржа: продажа/покупка/аукцион лотов между игроками

Квесты: ежедневные задания с наградами

Донат: Telegram Stars → NHDonate, круговые донаты, титулы

3. ЖИЗНЕННЫЙ ЦИКЛ ОБНОВЛЕНИЯ TELEGRAM
Порядок middleware (message и callback_query):

DbSessionMiddleware — async-сессия SQLAlchemy в data["session"]

UserLoaderMiddleware — загрузка/создание User по tg_id, проверка бана

NetworkErrorMiddleware — повтор при сетевых ошибках Telegram API

RateLimitMiddleware — лимит callback ~0.5 req/s на пользователя (Redis)

pre_checkout_query: только DbSessionMiddleware (оплата Stars)

Каждый handler получает session и user через middleware (dependency injection).
