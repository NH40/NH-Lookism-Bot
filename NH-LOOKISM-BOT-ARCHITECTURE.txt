NH-LOOKISM-BOT — ПОЛНАЯ АРХИТЕКТУРА ПРОЕКТА
================================================================================
Дата генерации: 2026-08-07
Язык: Python 3, aiogram 3, SQLAlchemy async, PostgreSQL, Redis, APScheduler.

--------------------------------------------------------------------------------
1. НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
Telegram-бот — текстовая MMORPG по мотивам Lookism: фазы Gang→King→Fist→Emperor,
кланы, карты, рейды, банк/казино, биржа, аукционы, квесты, донат через Telegram Stars.

--------------------------------------------------------------------------------
2. СЛОИ (ПАТТЕРН)
--------------------------------------------------------------------------------
Handlers (aiogram routers) → Services (бизнес-логика) → Repositories (запросы)
→ SQLAlchemy ORM → PostgreSQL.
Redis: FSM (состояния диалогов), все cooldown/lock, rate limit, кэш топов.

--------------------------------------------------------------------------------
3. ЖИЗНЕННЫЙ ЦИКЛ ОБНОВЛЕНИЯ TELEGRAM
--------------------------------------------------------------------------------
Порядок middleware (message и callback_query):
  1) DbSessionMiddleware — async-сессия SQLAlchemy в data["session"]
  2) UserLoaderMiddleware — загрузка/создание User по tg_id, бан
  3) NetworkErrorMiddleware — повтор при сетевых ошибках Telegram API
  4) RateLimitMiddleware — лимит callback ~0.5 req/s на пользователя (Redis)
pre_checkout_query: только DbSessionMiddleware (оплата Stars).

Каждый handler получает session и user через middleware (dependency injection).

--------------------------------------------------------------------------------
4. ТОЧКА ВХОДА (app/main.py)
--------------------------------------------------------------------------------
  init_db() — create_all таблиц
  init_cities() — идемпотентное создание gang-городов
