### #3 — разделение банд и кругов (дизайн пользователя)

- Круги не мешают играть бандам — как император с кругами.
- Когда круг захватывает город, он освобождает места для банд.
- При захвате городов PvP идёт только если у города есть игрок-король.
- Если игрок становится вторым королём города — он должен победить нынешнего короля.
- Если у проигравшего короля есть другие города — он теряет только этот город и остаётся с остальными;
  если других городов нет — падает до банды.
